# 40 · 田间测试与验收

> 目标：用可重复的测试矩阵验证 [00 总体方案](00-总体方案.md) 中的 KPI K1~K8。合成场景测试（CI）只证明软件逻辑正确；**验收以真实数据与田间测试为准**。

## 1. 测试层级

| 层级 | 环境 | 频率 | 工具 |
|---|---|---|---|
| T0 单元/集成 | CI（CPU，合成场景） | 每次提交 | `pytest`（60+ 用例，含端到端合成回放） |
| T1 台架回放 | 开发机，录制视频 + 真值 | 每个模型版本 | `smartview replay --log-detections` + `training/evaluate_field.py` |
| T2 静态场地 | 停机/慢速，布置标准异物 | 安装/标定后、每季度 | 标志物、卷尺/RTK、秒表、示波器 |
| T3 动态田间 | 真实收获作业 | 收获季 | 事件库、JSONL 日志、随车记录员 |
| T4 耐久/环境 | 整季作业 | 收获季 | 事件库统计、吹扫日志、硬件巡检 |

## 2. T0：合成场景（已实现，CI 自动）

| 用例 | 断言 |
|---|---|
| `pipe_forward` | 首次 L2 时钢管 ≥5 m、首次 L3 ≥4 m；事件入库、快照与片段存在；5~15 m 测距中位误差 ≤10 %、90 分位 ≤15 % |
| `stone_forward` | 首次 L2 ≥5 m |
| `empty` | 全程 ≤L1，无事件 |
| `header_selfview` | 启用排除区 ≤L1；禁用排除区 ≥L2（证明剔除割台的必要性） |
| `pipe_header` | 达到 L3 时钢管 ≥2.5 m |
| 自学习遮罩 | 学到的静止区域覆盖 ≥85 % 割台、≤5 % 地面 |
| 吹扫 / 报警 / 事件 / 健康 | 周期与脏污触发、占空比、抑制窗口；ack/mute/滞回/多相机升级；冷却合并；冻结/黑屏/脏污判定 |

## 3. T2：静态场地测试矩阵

**布置**：平整田间（收获后或留茬地）+ 一段真实玉米垄；在前视相机中线垄沟内及相邻行放置异物；地面每 5 m 设标志物用于标定与真值。

| 维度 | 取值 |
|---|---|
| 异物 | 8 寸井管段（露出 0.2 / 0.4 / 0.6 m，带/不带井台）、石块（15 / 25 / 40 cm）、水泥桩、铁桩、人体模型 |
| 距离（距割台前缘） | 1 / 2 / 3 / 5 / 8 / 10 / 15 / 20 m |
| 横向 | 中线、±0.6 m（相邻行）、±1.5 m（路径边缘）、±2.5 m（路径外，应 ≤L1） |
| 光照 | 顺光、逆光、黄昏（照度 <500 lx）、夜间补光 |
| 粉尘 | 无、人工扬尘（鼓风机 + 干土） |
| 遮挡 | 无、半遮挡（叶片）、仅露管口 |

**记录**：每个组合 ≥20 帧（停车）或 3 次慢速（1 m/s）通过；记录检出与否、类别、估距、首报等级与时间。

**判据**：K1/K2 按距离桶统计；估距误差 K8；路径外目标不得 ≥L2。

## 4. T3：动态田间测试

- 作业速度 4 / 6 / 8 km/h 各 ≥2 km 行程，提前在垄内埋设已知位置的异物（RTK 记录），记录首次 L2/L3 时刻与位置 → 预警距离/时间（K3）。
- 连续正常作业 ≥8 h 统计误报（K4）：事件库中每条 ≥L2 事件由记录员现场确认真/误。
- 端到端延迟（K5）：在相机视野内用 LED 同步闪烁 + 蜂鸣器输出接示波器，或高帧率手机拍摄 HMI 与现场，≥10 次取 95 分位。
- 割台自身零误报（K6）：空地行驶 30 min，排除区生效时无任何确认轨迹落在割台区域。
- 多相机融合：同一异物被前视与割台相机先后看到时，应在割台确认瞬间升至 L3；只在割台可见（前视漏检）时 ≤1.5 s 内 L3。

## 5. T4：环境与耐久

| 项目 | 方法 | 判据 |
|---|---|---|
| 粉尘 / 吹扫（K7） | 整日作业不人工擦镜；记录 `lens_dirty` 次数、吹扫次数、脏污持续时间 | 脏污状态累计 <5 % 作业时间；无因脏污漏报 |
| 振动 | 作业后检查相机角度、线缆、支架 | 外参漂移 <1°，否则重新标定 |
| 温度 | 午间高温与清晨低温各 2 h | 整机不降频（`tegrastats`），相机无丢帧 |
| 供电 | 频繁启停、熄火 | 事件库无损坏（WAL），服务 10 s 内恢复 |
| 存储 | 连续 7 天 | 片段目录受 `max_disk_gb` 控制，自动清理 |

## 6. 故障注入

| 故障 | 期望 |
|---|---|
| 遮住镜头 | 2 s 内"黑屏/遮挡"→ L1 视觉提示 + HMI 标红 |
| 拔掉相机 | 2 s 内"相机离线"→ L1，其余相机继续工作 |
| 定格画面（回放卡住） | 2 s 内"画面冻结" |
| 镜头涂泥点 | 60 s 内"镜头脏污" + 自动吹扫 + 日志 |
| GNSS 失锁 | 3 s 内回退手动车速，HMI 徽标显示"GNSS 失锁" |
| HMI 断网 | 蜂鸣器/灯继续工作（GPIO 独立），HMI 重连后状态恢复 |
| 进程被杀 | systemd 3 s 内拉起；GPIO 关断（无长鸣） |

## 7. 验收标准汇总

| KPI | 验收门限 | 测试层级 |
|---|---|---|
| K1 井管 ≥3 m 检出率 | ≥98 %（≥200 次采样） | T2 + T3 |
| K2 ≥15 cm 石块检出率 | ≥90 % | T2 + T3 |
| K3 前视预警时间 | ≥2.5 s（95 分位） | T3 |
| K4 误报 | ≤1 次/小时 | T3（≥8 h） |
| K5 延迟 | ≤150 ms（95 分位） | T3 |
| K6 割台零误报 | 0 | T3 |
| K7 粉尘可用性 | 8 h 无需人工擦镜 | T4 |
| K8 测距 | 中位 ≤10 %、90 分位 ≤15 %（5~15 m） | T2 |

未达标项需给出根因（数据 / 模型 / 标定 / 硬件）与整改计划后复测。

## 8. 安全注意事项

- 场地测试时割台停转或抬起；动态测试埋设异物只用软质替代品（木桩、泡沫包裹的管段），**严禁**用真实钢管做动态碰撞测试。
- 现场人员不得进入作业路径 20 m 内；人体模型测试用于验证 `person` 类。
- 一期系统只报警不干预，驾驶员始终负责操作；HMI 启动页与说明书明示。

## 9. 数据回收流程

1. 每日作业结束用 `smartview export-events` 导出 CSV，拷贝 `clips/` 与 JSONL 日志。
2. 记录员标记每条事件真/误，形成当日表格。
3. 每周汇总到数据集回标队列（见 [30 §7](30-感知算法与数据方案.md)）。
