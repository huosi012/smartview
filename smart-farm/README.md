## 方案要点

**温室本体**：5.6 m × 9.0 m（50.4 ㎡），双坡屋面，檐高 2.8 m、脊高约 4.1 m（坡度 25°）。
热镀锌方管骨架、深灰色氟碳漆（高级灰，比常见白色大棚显档次），柱距 1.125 m；
屋面 10 mm 透明阳光板，立面 8 mm 透明阳光板；0.35 m 高深灰铝塑板勒脚；屋脊两侧共 4 樘天窗。

**入口**：温室山墙正对走廊。走廊栏杆开 1.8 m 宽口子，做 3 级防滑木塑台阶（每级 15 cm），
两侧加不锈钢扶手和可上锁的护栏门；木塑栈道直通入口门头。门头为深灰铝塑板包封，
内衬木纹，上设不锈钢发光字「智慧农场」和「SMART FARM · 劳动教育实践基地」，配双扇推拉玻璃门。

**内部布置**（从入口往里）：

- 中央通道 1.8 m，木塑地板；
- 左侧前段：气雾栽培立柱 6 根（约 250 株，最出效果的“科技感”元素）；
- 左侧后段：A 字形管道水培架 2 组（约 130 株）；
- 右侧：班级责任田种植箱 4 个（1.6 m × 1.2 m × 0.68 m，一个年级一箱，带班级铭牌）；
- 尽端：55 寸智慧农场大屏 + 教学台（正对入口，进门第一眼）；左角育苗架（三层 LED 补光），右角水肥一体机 + 营养液罐；
- 顶部：LED 补光灯带 12 条、喷雾降温管线 2 路、温湿度传感器、监控摄像头。

**室外**：人造草坪（保护原屋面防水层，比铺装轻）、白色鹅卵石排水带、黄杨球花箱、观赏草花箱、
户外花箱 3 个、木塑长凳 2 条、小型气象站；原有展板更新为科普展板。

## 施工前必须确认

1. **屋面荷载**：请结构专业复核（学校上人屋面活荷载通常约 2.0 kN/㎡）。温室本体很轻，约 15–20 kg/㎡；
   重的是种植箱，所以用轻质基质（≤ 600 kg/m³），土层控制在 25–30 cm，箱底加分载龙骨。
2. **防水**：不在防水层上随意打孔。优先用配重墩，必须锚固时打在结构板上，并做附加防水。原排水坡向和地漏不能被地板挡住。
3. **抗风**：屋面风大，底梁锚固，阳光板用铝压条全周固定，天窗配限位器。
4. **安全**：开口处护栏门可上锁，台阶防滑并设扶手；室内用电为防水插座，加漏电保护。
5. **夏季降温**：天窗 + 喷雾 + 内遮阳网，必要时加 1 台排风扇。
6. **朝向**：效果图按示意方向出图；现场确认真实朝向后，阳光板防紫外线面朝外。

## 重新出图

所有模型由代码生成（Blender `bpy` + Cycles），改尺寸后可直接重渲：

```bash
pip install bpy==5.2.2 pillow
python textures.py                     # 生成大屏画面、展板贴图
python scene.py --time day  --shots hero,terrace,terrace_e,aerial --res 1920x1280 --samples 64
python scene.py --time day  --shots interior --res 1920x1280 --samples 96
python scene.py --time day  --shots plan --res 1800x1800 --samples 48 --sun-elev 60 --sun-az 60
python scene.py --time dusk --shots dusk,hero_dusk --res 1920x1280 --samples 96
python annotate.py                     # 调色、加标题、生成带图例的平面图 -> renders/final/
```

主要尺寸参数在 `scene.py` 顶部（`GW`、`GL`、`EH`、`PITCH`、露台范围、开口位置等）。
