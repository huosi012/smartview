# 名表维修 · 抖音封面模板

名表维修抖音号的主页封面模板，做成「画框」形式：手表照片放在框里，品牌、型号、服务这些文字都排在照片外面，不压在表上。用 PowerPoint 或 WPS 打开，换照片、改文字，导出就是 1080×1440（3:4）的抖音封面。

![三种风格](previews/1-三种风格.jpg)

## 文件说明

| 文件 | 用途 |
|---|---|
| `抖音封面模板.pptx` | 模板本体。第 1–4 页是说明，第 5–7 页是三种风格的封面模板 |
| `fonts/` | 模板用到的 4 个字体，第一次使用前需要安装 |
| `previews/` | 每一页的预览图和三种风格的主页效果图，可以直接用微信发给客户 |
| `src/` | 生成这个 PPT 的脚本，只有改设计时才用得到 |

## 三种风格

- **A 暗夜画廊（推荐）**：黑卡纸配香槟金细线框，标题居中，像画廊里的展品。
- **B 象牙画册**：米白纸张质感，照片像印在拍卖图录上，右侧是大号期数。在深色的抖音主页里最显眼。
- **C 维修档案**：照片四角有取景框，下方是「品牌 / 项目」档案表格，突出专业维修。

三种都没有亮黄色、描边和粗黑体，高级感靠留白、宋体和细线。整个主页只用其中一种，九宫格才整齐。各风格的主页效果：[A](previews/主页效果-A-暗夜画廊.jpg)、[B](previews/主页效果-B-象牙画册.jpg)、[C](previews/主页效果-C-维修档案.jpg)。

## 每次出封面

1. **安装字体（只做一次）**：双击 `fonts/` 里的 4 个字体文件，点「安装」；Mac 用「字体册」。装好后重开 PPT/WPS，不然字体会被替换成默认字体。
2. **复制一页模板**：左侧缩略图里右键模板页，选「复制幻灯片」，在副本上改。
3. **换照片**：右键照片 →「更改图片」。也可以选中照片按 Delete，再点画框中间的图标插入，照片会自动裁成画框大小。
4. **调位置**：双击照片 →「裁剪」，拖动照片让表盘居中。选择窗格（开始 → 选择 → 选择窗格）里有隐藏的「构图参考线」，可以打开对位，对好后一定要再隐藏，否则会被一起导出。
5. **改文字**：店名、期数、品牌、型号、服务项目都可以直接点开改，字多了会自动缩小。型号 2–6 个字最好看。
6. **导出**：
   - PowerPoint：文件 → 导出 → 更改文件类型 → PNG → 仅当前幻灯片。
   - WPS：文件 → 输出为图片 → 当前页，或 另存为 → PNG。
7. **发抖音**：发布页「选封面」，从相册上传这张图。

页面尺寸是 11.25 × 15 英寸。PowerPoint 默认按 96 dpi 导出，所以导出来正好是 1080×1440。

## 拍摄建议

具体做法见 [拍摄建议](previews/4-拍摄建议.jpg)：
- **光线**：一盏柔光灯从左上 45° 打光，右侧放白卡补一道高光。
- **背景和角度**：黑色或深灰植绒布做背景，表立在表枕上，表盘向左转约 25° 露出表冠，镜头略高于表盘中心。
- **构图**：画框接近正方形，手机竖拍 3:4 时照片上下会被裁掉一些，所以表放正中、四周多留空。

主页有两块地方会被抖音界面挡住，模板已经避开了：左下角是点赞数，置顶视频的左上角有「置顶」标签。

## 字体与授权

封面上用到的字体都是 SIL Open Font License 1.1 开源字体，可以免费商用，封面图发到抖音没有问题。授权全文在 `fonts/licenses/`。

| 字体 | 用在 | 来源 |
|---|---|---|
| 思源宋体 SemiBold（Noto Serif SC SemiBold） | 型号大标题 | Google / Adobe |
| 思源宋体 Regular（Noto Serif SC） | 服务项目、店名等小字 | Google / Adobe |
| Cormorant Garamond SemiBold | 英文品牌名、店名英文 | Christian Thalmann |
| Cormorant Garamond Medium Italic | 期数编号 N° 023 | Christian Thalmann |

两个思源字体是用 Google Fonts 的分片文件合并出来的单文件。家族名改成了「Noto Serif SC SemiBold」和「Noto Serif SC」，这样 PPT 里能稳定找到。

说明页正文用的是系统自带的微软雅黑。这几页只是给人看的说明，不会出现在封面上。

## 示例照片

模板里的示例照片取自客户发来的截图（屏幕翻拍，清晰度有限），只用来示意。正式出图时换成用柔光灯拍的新照片。

## 重新生成（改设计时用）

需要 Python 3（Pillow、numpy、fontTools）、Node.js、LibreOffice 和 poppler，并且装好 `fonts/` 里的字体：

```bash
cd src
./render.sh          # 素材 → 示例封面 → 效果图 → 抖音封面模板.pptx → previews/
```

- `src/make_assets.py`：画框背景、构图参考线、拍摄示意图，以及示例照片在画框里的摆位。画框窗口的位置和大小在 `WINDOWS` 里，`build.js` 里也有一份，改的时候两边要同步。
- `src/build.js`：用 pptxgenjs 生成 PPT，版式、字号、颜色都在这里。
- `src/make_mockups.py`：把示例封面拼成主页九宫格效果图。
- `src/export_previews.py`：把渲染好的 PPT 页面导出成 `previews/` 里的 JPG。
- `src/merge_font_slices.py`、`src/fix_font_names.py`：把 Google Fonts 的分片字体合并成单个文件，并修正家族名。
