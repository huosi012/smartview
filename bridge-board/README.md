# 桥梁探究展板（校园科技节）

五年六班 · 安沫宣小组「我们的桥梁探究之旅」展板，成品尺寸 **宽 76 cm × 高 176 cm**（竖版）。

## 文件

| 文件 | 用途 |
|---|---|
| `桥梁探究展板_76x176cm.pdf` | **交给印刷店的文件**。矢量文字、字体已嵌入，页面 760 × 1760 mm |

## 印刷说明

- 按 1:1 输出，不要等比缩放到其他尺寸。
- 版面没有预留出血。如果印刷店要求 3–5 mm 出血，请他们用底色向外延展，或告诉我重新导出。
- 照片在成品上的分辨率都在 126 dpi 以上，户外展板观看距离下足够清晰。
- 字体：思源黑体（Noto Sans SC）、站酷庆科黄油体，均为 SIL OFL 开源免费商用字体。

## 版面结构

顶部：大标题、副标题，以及班级（五年六班）、指导教师（尹洪雨、孙昊）、7 名组员。

1. **项目简介**：“桥，连接此岸与彼岸”项目导语，以及“设计 → 制作 → 测试 → 迭代”工程流程图
2. **问题驱动**：30 厘米“小河”示意图、核心挑战、“以为 vs 发现”
3. **项目推进**：四站路线（平板桥 → 拱桥 → 悬索桥 → 斜拉桥），每站配实拍照片（平板桥用放上可乐后压弯的那张）
4. **成果展示**：科学原理（四种桥的受力图，每张下面配一座沈阳的真桥，和 03 的四站一一对齐）、四条探究收获（只留标题），以及“终极成果：现场搭建倍力桥”（先是 9 步拼装图纸，再是团队站在桥上的实拍照、现场搭建目的、一行邀请语）

板块之间用一句过渡语串起来：目标有了，可第一次动手就遇到了难题 → 带着这个问题，我们一次次改进 → 四次尝试之后，我们找到了答案；倍力桥标题旁写“用上「三角形 + 模块化」”，接住上面的收获。

## 重新导出

```bash
# 1. （可选）从原 PPT 重新处理图片
python tools/prep_images.py <PPT解压后的 ppt/media 目录> <放 1.jpg、2.jpg 的目录> source/img
# 2. 改过文字后，用完整字体重新做子集（否则新字会缺字）
python tools/subset_fonts.py <完整字体目录> source
# 3. 导出 PDF
node tools/render.js source <输出目录> --pdf
```

`render.js` 依赖 Playwright 自带的 Chromium。完整字体可从 Google Fonts 下载：Noto Sans SC（400/500/700/900）和 ZCOOL QingKe HuangYou，文件名需与 `subset_fonts.py` 里的一致。
