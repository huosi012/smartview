# 3.2m×20m 电子汽车衡基础施工图

依据厂家条件图 ZCS3018D（四节 U 形梁浅基坑）及《中国黑龙江自由贸易试验区黑河片区中小企业孵化基地二期项目岩土工程勘察报告》编制的结构施工图。

## 一张图版本（`output/`）

- `汽车衡基础施工图(一张图).dxf` / `.pdf`：全部内容排在一张 A0 加长图（2080×841）上，自左至右依次为：
  基础平面布置图、1-1～4-4 剖面、底板配筋平面图、图例及预埋件统计表 → 墩梁/墙/引道板配筋图、钢筋表 →
  节点详图、预埋件详图、预埋件材料表、工程量表 → 结构设计总说明。

## 分张版本（`output/`）

| 图号 | 图名 | 主要内容 |
|---|---|---|
| 结施-01 | 结构设计总说明 | 工程概况、设计依据、地质摘要、基础方案及计算结果、材料、地基处理、构造、预埋件精度、排水接地、图纸目录、工程量 |
| 结施-02 | 基础平面布置图 | 轴线、定位尺寸、检修口、排水沟/集水坑、引道板、换填范围、预埋件统计表 |
| 结施-03 | 基础剖面图 | 1-1 纵剖面，2-2、3-3、4-4 横剖面，换填、冻深线、水位线 |
| 结施-04 | 基础配筋图及钢筋表 | 底板配筋、ZL-1/ZL-2 墩梁、端墙 Q2、侧墙 Q1、引道板 YB-1，钢筋表 |
| 结施-05 | 预埋件及节点详图 | 端墙顶部节点、检修口、排水沟绕行、M-1~M-4、GB-1、接地、穿线管 |

- `结施-0X *.dxf`：单张图（A1 图框，1:50 出图比例，模型空间单位 mm）。内容与一张图版本相同，按需选用。
- `汽车衡基础施工图(全套).dxf`：五张图并排放在一个文件中。
- `汽车衡基础施工图(预览).pdf`：预览用 PDF。

DXF 文字样式 `HZ` 使用仿宋（simfang.ttf），宽度系数 0.7；图层按 `S-*` 分类，打印时按图层线宽出图即可。

## 与厂家示意图相比的主要调整

1. 场地为强冻胀砾砂（标准冻深 2.50m、最大冻深 2.80m），且地下水位高：取消毛石混凝土墩，改为整体钢筋混凝土基础（底板 + 5 道墩梁 + 侧墙 + 端墙），基础下至 -3.000 换填非冻胀性级配砂石。
2. 地下水位高，取消渗水井，改为③轴集水坑 + DN150 排水管接室外雨水井。
3. ±0.000 绝对标高不宜低于 135.000，使坑底高于抗浮设防水位 134.500。
4. 补充配筋、钢筋表、预埋件详图、引道板、接地及穿线管做法。

图纸须经具备资质的设计单位审核签章后方可用于施工；带“※”的尺寸须与汽车衡厂家复核。
