# 我为核安全文化代言 · 互动大屏

给 14 m × 5 m 大屏做的互动页面：

* **背景里 24 个人的照片围成一圈，一直循环转动**。开场时，照片从中间旋转着散开出场。
* 领导念到谁，**后台操作员点那个人**，圈会先转到把他送到正中间，然后照片飞出放大，同时展开一块红金色的人物展板：左边是姓名、单位和一句话事迹，右边是个人简介。
* 再点一下，照片飞回圈里，继续转动。

## 怎么打开

成品是 **`output/我为核安全文化代言-大屏.html`**，只有一个文件，图片都已经内嵌。

1. 拷到大屏播放电脑上，双击用 **Chrome 或 Edge** 打开。
2. 把窗口拖到大屏上，按 `F` 进入全屏。
3. 按 `C` 打开**后台控制面板**，把这个小窗口拖到操作员自己的显示器上。

> 播放电脑的显示设置请用“扩展”模式：大屏显示全屏页面，操作员显示器上放控制面板。如果是“复制”模式（两个屏幕显示一样的内容），也可以直接在画面上点照片：鼠标移到照片上，圈会停下来，方便点击。

## 后台怎么操作

| 想做的事 | 操作 |
| --- | --- |
| 放大某个人 | 在控制面板里点他的名字；或直接点大屏画面上的照片；或输入编号（如 `1` `2` = 第 12 位） |
| 快速找人 | 控制面板顶部的搜索框里输入姓名或单位，回车放大第一个结果 |
| 收回 | 再点一次同一个名字 / 点“返回总览” / 按 `Esc` / 点画面任意处 |
| 按顺序放大下一位、上一位 | 翻页笔“下一页”“上一页” / `→` `←` / 控制面板上的按钮 |
| 重新播放出场动画 | `S` / 控制面板“重新入场” |
| 显示快捷键帮助 | `H` |

* 放大一个人的时候直接点另一个人，会自动切换，不用先收回。
* 鼠标停 3 秒后光标会自动隐藏，圈也会恢复转动。
* 如果浏览器提示“已拦截弹出窗口”，请在地址栏右侧选择“始终允许”，再按 `C`。

## 更新人员信息、照片和背景

所有内容都在 **`config.js`** 里：

1. 修改每个人的 `name`（姓名）、`unit`（单位）、`bio`（个人简介，分段用 `\n`）。人数可增可减，圈会自动调整。
   `highlight` 是一句话事迹，用金色大字显示在姓名、单位下方；留空就不显示。现在前 8 人的 `highlight` 是从各自简介里原样摘出来的一句，可以改。
2. 照片放进 `photos/` 文件夹，在对应人员的 `photo` 填路径，例如 `"photos/09.jpg"`。照片会裁成 3:4 显示在圈上，放大时显示完整照片。如果脸被裁到了，可以加一项 `"focus": "50% 20%"`，让裁切位置偏上。
3. 14 m × 5 m 底图：把图片放进 `assets/`，在 `background` 填路径。底图上已经有标志和标题的话，把 `logo` 和 `titleImage` 改成 `""`。`background` 留空时，用内置的红色背景。
4. 转速、圈的大小和位置在 `carousel` 里调。比如 `secondsPerTurn` 是转一圈的秒数。`introOnLoad` 改成 `false`，打开页面时照片先不出现，等按 `S` 再出场。
5. 重新打包成单文件：

   ```bash
   pip install -r requirements.txt
   python3 tools/build.py
   ```

修改调试时，可以直接双击打开 `index.html` 预览，它会读取 `config.js`、`assets/` 和 `photos/`。

## 注意

* 现在只有前 8 个人的姓名、单位、简介和照片，都是从之前那张海报上识别、截取的。第 9–24 位是占位内容，等正式资料来了再替换。
* 海报上截下来的照片分辨率很低，放大到 14 米的屏上会糊，正式使用请换成每个人的原始照片。

## 目录结构

```
index.html          大屏页面（读取 config.js）
config.js           人员数据和旋转参数（唯一需要编辑的文件）
assets/             标志、标题、底图
photos/             人员照片
tools/build.py      打包成 output/ 里的单文件
output/             成品
```
