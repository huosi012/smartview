# smartview

## count-animation.html

PPT 首页用的“千名学子圆梦”动画，发布会风格，顺易教育品牌蓝 + 橙配色，WebGL 三维渲染：

- 整面墙按格子依次排开：内部是学生海报，四周一圈是成绩单，中间没有色块，标题直接浮在墙上，文字后面的墙面虚化压暗、向外柔和过渡。
- 镜头从侧面贴近墙面开始，一边绕到正面一边拉远；卡片有厚度、背面、光泽和运动模糊，数字和闪光有泛光。
- 学生海报先从镜头两侧冲进来，汇成一圈绕着数字旋转的倾斜光环；再依次脱离光环、翻转着落到墙上。成绩单最后从画面外边飞边翻面落到四周。
- 舞台聚光灯：开场两盏灯闪亮打开，计数时在墙上来回扫，光束里的光点被照亮；到 1000 时停在标题两侧，主灯从上方打下来。
- 完成时数字到 1000，“+”弹出，横向光闪过，一道光扫过整面墙，标语出现。

用法：

1. 用最新版 Chrome / Edge 直接双击打开 `count-animation.html`（不需要联网、不需要服务器）。浏览器要打开硬件加速，否则三维画面会卡。
2. 点“选择学生图片”选中全部学生海报，再点“选择成绩单图片”选中成绩单。都按文件名排序，格子比图片多时轮流重复使用。
3. 做 PPT 首页推荐点“全屏录制”（1080p 屏幕录出来就是 1920×1080）。在 ScreenToGif 里框住画面，开始录制后按空格播放，播完停止录制。
4. 放进 PPT 建议导出 MP4（插入 → 视频 → 此设备，开始方式设为“自动”）。GIF 只有 256 色，照片多时体积大、有颗粒。

页面上可以改录制尺寸、节奏、墙面密度、计数终点、顶部小字、标语和英文小字。字体都内嵌在文件里，不用联网。图片只在本机浏览器里处理，不会上传。
