# 我为核安全文化代言 · 互动大屏

这是给 14 m × 5 m 大屏做的交互页。底图就是整张海报。领导念到谁，操作员点一下这个人的照片（或按一下翻页笔），照片就从海报上的原位置飞到屏幕中间放大，同时显示**姓名、单位和个人简介**。再点一下，照片飞回原位。

## 成品（`output/` 目录）

| 文件 | 说明 |
| --- | --- |
| `我为核安全文化代言-交互版.pptx` | PowerPoint 版，页面尺寸 140 cm × 50 cm（按 1:10 对应 14 m × 5 m） |
| `我为核安全文化代言-网页版.html` | 网页版，只有一个文件，图片已经内嵌。双击用 Chrome 或 Edge 打开，按 `F` 全屏 |

两个版本效果一样，用其中一个就行。网页版动画最顺，对软件版本也没要求。

## 现场操作

| 想做的事 | PPT 版（放映状态） | 网页版 |
| --- | --- | --- |
| 放大某个人 | 点他的照片 | 点他的照片，或按数字键 `1`–`8` |
| 按顺序放大下一位 | 翻页笔“下一页” / `→` / 空格 | 翻页笔“下一页” / `→` / 空格 |
| 上一位 | 翻页笔“上一页” / `←` | 翻页笔“上一页” / `←` |
| 回到总览 | 在放大页上随便点一下 / `Home` | 随便点一下 / `Esc` / `0` / `B` |
| 直接跳到第 N 位 | 输入 N+1 再按回车（第 1 页是总览） | 数字键 `N` |

* 照片“飞出放大”靠的是 PPT 的**平滑（Morph）切换**。PowerPoint 2019、2021 和 Microsoft 365 都支持。PowerPoint 2016 及更早的版本会自动改成淡入淡出，点击和跳转照常能用。如果现场用 WPS，请先在播放电脑上试一遍。
* PPT 已经设成**循环放映**：放完最后一位会回到总览，大屏上不会出现黑屏的“放映结束”。
* 点海报上的空白处不会翻页，这是为了防止误点。只有点照片或点放大页才会跳转。
* 第 1 页是总览，第 2–9 页依次对应 8 个人。页面之间靠超链接跳转，**请不要删除页面或调整页面顺序**。演讲者备注里有每页对应的人员名单。
* 网页版：鼠标停 3 秒后光标会自动隐藏；按 `H` 显示快捷键帮助；按 `D` 显示可点击区域（换了底图后用来核对位置）。
* 播放电脑需要装“微软雅黑”字体（Windows 系统自带）。

## 更新人员信息 / 照片

所有内容都在 **`config.js`** 里，网页版和 PPT 用的是同一份数据：

1. 修改每个人的 `name`（姓名）、`unit`（单位）、`bio`（个人简介，分段用 `\n`）。
2. 把原始高清照片放进 `photos/` 文件夹，再把对应人员的 `photo` 改成文件路径，比如 `"photos/01.jpg"`。`photo` 留空时，会直接用海报上截下来的照片。照片横竖都可以，放大后的版面会自动适配。
3. 重新生成成品：

   ```bash
   pip install -r requirements.txt
   python3 tools/build.py
   ```

4. 换高清底图：直接替换 `assets/poster.jpg`。海报版式不变的话，坐标不用改。版式变了，就改 `config.js` 里的 `photoArea`（照片位置）和 `hotspot`（可点击区域），然后打开 `index.html` 按 `D` 核对。

> 平时修改调试时，可以直接打开 `index.html`（它读取 `config.js`、`assets/`、`photos/`）。`output/` 里的网页版是打包好的单文件，拷到播放电脑上最方便。

## 注意

* **底图分辨率**：现在的 `assets/poster.jpg` 只有 2000 × 714 像素，放到 14 米的大屏上会糊。正式使用前，请换成设计稿导出的高清图，宽度按大屏实际分辨率来，例如 P2.5 屏约 5600 × 2000。
* **照片清晰度**：现在放大显示的照片是从海报上截下来的，同样不够清晰，建议换成每个人的原始照片。
* **人员信息**：现在 `config.js` 里的姓名、单位和简介是从海报上识别出来的**占位内容**，等正式资料来了再替换。

## 目录结构

```
index.html          网页版主页面（读取 config.js）
config.js           人员数据与坐标（唯一需要编辑的文件）
assets/poster.jpg   底图（整张海报）
photos/             原始照片（可选）
tools/build.py      生成 output/ 里的 PPT 和单文件网页版
output/             成品
```
