# smartview

## count-animation.html

喜报图片依次飞来，像拼图一样拼成“1000”，下方金色数字从 1 滚动到 1000，最后显示“1000+”和标语。红金配色，用作 PPT 首页动画，配合 ScreenToGif 录制。拼图文字可以改，比如改成 2027。

用法：

1. 用 Chrome / Edge 直接双击打开 `count-animation.html`（不需要联网、不需要服务器）。
2. 点“选择图片”一次选中全部图片（按文件名排序），或把图片拖进页面。
3. 做 PPT 首页推荐点“全屏录制”（1080p 屏幕录出来就是 1920×1080）。在 ScreenToGif 里框住画面，开始录制后按空格播放，播完停止录制。
4. 放进 PPT 建议导出 MP4（插入 → 视频 → 此设备，开始方式设为“自动”）。GIF 只有 256 色，深色渐变会有颗粒，体积也大得多。

页面上可以改录制尺寸、节奏、拼图文字、计数终点、顶部小字、标语和英文小字。字体都内嵌在文件里，不用联网。图片只在本机浏览器里处理，不会上传。
