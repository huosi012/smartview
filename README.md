# 我为核安全文化代言 · 互动大屏

给 14 m × 5 m 大屏做的互动页面：

* **背景里 24 个人的照片围成一圈，一直循环转动**。开场时，照片从中间旋转着散开出场。
* 领导念到谁，**后台操作员点那个人**，圈会先转到把他送到正中间，然后照片飞出放大，同时展开一块红金色的人物展板：左边是姓名、单位和一句话事迹，右边是个人简介。
* 再点一下，照片飞回圈里，继续转动。

## 怎么打开

成品是 **`output/我为核安全文化代言-大屏.html`**，只有一个文件，图片都已经内嵌。

1. 拷到大屏播放电脑上，双击用 **Chrome 或 Edge** 打开。
2. 把窗口拖到大屏上，按 `F` 进入全屏。
3. 按 `C` 打开**后台控制面板**，把这个小窗口拖到操作员自己的显示器上。

> 播放电脑的显示设置请用“扩展”模式：大屏显示全屏页面，操作员显示器上放控制面板。如果是“复制”模式（两个屏幕显示一样的内容），也可以直接在画面上点照片：鼠标移到照片上，圈会停下来，方便点击。

## 后台怎么操作

| 想做的事 | 操作 |
| --- | --- |
| 放大某个人 | 在控制面板里点他的名字；或直接点大屏画面上的照片；或输入编号（如 `1` `2` = 第 12 位） |
| 快速找人 | 控制面板顶部的搜索框里输入姓名或单位，回车放大第一个结果 |
| 收回 | 再点一次同一个名字 / 点“返回总览” / 按 `Esc` / 点画面任意处 |
| 按顺序放大下一位、上一位 | 翻页笔“下一页”“上一页” / `→` `←` / 控制面板上的按钮 |
| 重新播放出场动画 | `S` / 控制面板“重新入场” |
| 导入 / 修改人员资料、选择背景 | `I` / 控制面板“资料与背景” |
| 显示快捷键帮助 | `H` |

* 放大一个人的时候直接点另一个人，会自动切换，不用先收回。
* 鼠标停 3 秒后光标会自动隐藏，圈也会恢复转动。
* 如果浏览器提示“已拦截弹出窗口”，请在地址栏右侧选择“始终允许”，再按 `C`。

## 导入人员资料、选择背景

在大屏页面按 `I`，或在控制面板里点“资料与背景”，打开资料窗口：

1. 点“导入 Word / Excel / 照片”，或直接把文件拖进窗口，可以一次拖多个文件。
   * **Word（.docx）**：按你们现在的写法即可。每人一段，第一行写“单位-姓名”（如“中电华元-李哲”“山东核电 运行一处-代子星”），下面是个人简介，照片插在简介后面。
   * **Excel（.xlsx）**：第一行是表头“姓名、单位、一句话事迹、个人简介、照片文件名”。照片有两种给法：直接插在对应那一行里（WPS 的“嵌入单元格图片”也行）；或者在表里填照片文件名，再把照片文件一起拖进来。点“下载 Excel 表”能得到模板，里面是当前名单。
   * **照片文件**：文件名写成姓名（如“李哲.jpg”），会自动配给对应的人。
   * 旧格式的 .doc / .xls 文件，请先另存为 .docx / .xlsx 再导入。
2. 在表格里核对。可以改字、换照片（点照片框，或把照片拖到框上）、补“一句话事迹”、调整顺序、删除或添加人员。
   导入方式默认是“替换整个名单”，也可以改成“追加到名单后面”。
3. **大屏背景**：在“大屏背景”这一行点“选择背景图片…”，或把图片拖到预览框上。建议用 14:5、宽度 5000 像素以上的图，比例不对或分辨率偏低时会有提示。背景图上已经有标志和标题的话，请取消勾选“显示顶部标志和标题”。点“恢复默认红色背景”可以换回原来的背景。
4. 点“**保存并应用到大屏**”，选一个保存位置，就会存成一个新的大屏文件（含全部照片），大屏也会立即换成新名单。**以后请打开这个新文件**，原来的文件不会被修改。

## 开发者：修改 config.js 并打包

也可以直接改源文件，所有内容都在 **`config.js`** 里：

1. 修改每个人的 `name`（姓名）、`unit`（单位）、`bio`（个人简介，分段用 `\n`）。人数可增可减，圈会自动调整。
   `highlight` 是一句话事迹，用金色大字显示在姓名、单位下方；留空就不显示。现在前 8 人的 `highlight` 是从各自简介里原样摘出来的一句，可以改。
2. 照片放进 `photos/` 文件夹，在对应人员的 `photo` 填路径，例如 `"photos/09.jpg"`。照片横版、竖版都可以：圈上卡片的宽度和放大后的相框都跟着照片比例变，照片完整显示，不会把人裁掉。只有比例特别极端的照片（比 9:5 还宽，或比 3:5 还窄）才会被裁切，这时可以加一项 `"focus": "70% 50%"` 指定保留哪一侧。
3. 14 m × 5 m 底图：把图片放进 `assets/`，在 `background` 填路径；留空时用内置的红色背景。底图上已经有标志和标题的话，把 `showHeader` 改成 `false`。
4. 转速、圈的大小和位置在 `carousel` 里调。比如 `secondsPerTurn` 是转一圈的秒数。`introOnLoad` 改成 `false`，打开页面时照片先不出现，等按 `S` 再出场。
5. 重新打包成单文件：

   ```bash
   pip install -r requirements.txt
   python3 tools/build.py
   ```

修改调试时，可以直接双击打开 `index.html` 预览，它会读取 `config.js`、`assets/` 和 `photos/`。

## 注意

* 现在只有前 8 个人的姓名、单位、简介和照片，都是从之前那张海报上识别、截取的。第 9–24 位是占位内容，等正式资料来了再替换。
* 海报上截下来的照片分辨率很低，放大到 14 米的屏上会糊，正式使用请换成每个人的原始照片。

## 目录结构

```
index.html          大屏页面（读取 config.js）
importer.js         人员资料导入 / 编辑（Word、Excel、照片）
config.js           人员数据和旋转参数
assets/             标志、标题、底图
photos/             人员照片
tools/build.py      把以上内容打包成 output/ 里的单文件
output/             成品
```
