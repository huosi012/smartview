# smartview

## count-animation.html

PPT 首页用的“千名学子圆梦”动画，发布会风格，WebGL 三维渲染：

- 两套整体风格，页面上切换：
  - 明亮（默认）：浅色舞台，照片保持原色，中间是白色雾面，品牌蓝大字 + 橙色“+”，和学生海报同一套配色。
  - 深色舞台：蓝色舞台，墙上照片调成品牌蓝调，白色大字，聚光灯光束明显。
- 中间区域左上角是顺易教育 LOGO（深色风格自动用白字版本），可以在页面上关掉，改成在顶部居中显示一行文字。
- 墙面密度默认约 1000 格（可选约 190 / 500 / 1000 / 1600 格），看起来就是上千张照片。整面墙按格子依次排开：内部是学生海报，四周一圈是成绩单，中间没有色块，标题直接浮在墙上，文字后面的墙面虚化成雾面、向外柔和过渡。
- 镜头从侧面贴近墙面开始，一边绕到正面一边拉远；卡片有厚度、背面、光泽和运动模糊，数字和闪光有泛光。
- 学生海报先从镜头两侧冲进来，汇成一圈绕着数字旋转的倾斜光环；再依次脱离光环、翻转着落到墙上。成绩单最后从画面外边飞边翻面落到四周。
- 舞台聚光灯：开场两盏灯闪亮打开，计数时在墙上来回扫，光束里的光点被照亮；到 1000 时停在标题两侧，主灯从上方打下来。
- 完成时数字到 1000，“+”弹出，横向光闪过，一道光扫过整面墙，标语出现。

用法（本地运行）：

1. 把 `count-animation.html` 存到电脑上，用最新版 Chrome / Edge 双击打开。不需要联网、不需要服务器，字体、LOGO、视频导出工具都已经打包在这一个文件里。浏览器要打开硬件加速，否则三维画面会卡。
2. 点“选择学生图片”选中全部学生海报，再点“选择成绩单图片”选中成绩单。墙面默认约 1000 格（内部 765 格学生海报、外圈两层 264 格成绩单），每落一张计数加 1。图片少也可以：洗牌后轮流使用，每张用到的次数一样，并且学生图 30 张以上时同一张图周围两圈内不会重复，10 张以上时相邻格子不会重复。成绩单每张会取 4 种不同的取景（整页、顶部姓名和二维码、中部分数表、底部位次表），10 张以上时同一张成绩单的不同取景也不会挨在一起。只换了一种图时，页面会提醒另一种还是示例图。
3. 选好画面尺寸，点“导出 MP4”。页面逐帧生成视频并弹出“另存为”，不用录屏，也不用装 FFmpeg。Chrome / Edge 正式版导出的是 H.264，可以直接插入 PPT。
4. PPT 里“插入 → 视频 → 此设备”，开始方式设为“自动”，播完停在最后一帧。

也可以按空格播放后用 ScreenToGif 录屏（导出 MP4 需要在 ScreenToGif 选项 → 额外里配置 FFmpeg）。

页面上可以改录制尺寸、节奏、墙面密度、计数终点、顶部小字、标语和英文小字。字体都内嵌在文件里，不用联网。图片只在本机浏览器里处理，不会上传。
