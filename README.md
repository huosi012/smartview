# smartview

## count-animation.html

喜报图片依次飞向画面中间，中间数字从 1 滚动到 1000，最后显示“1000+”和标语。用于配合 ScreenToGif 录成 GIF。

用法：

1. 用 Chrome / Edge 直接双击打开 `count-animation.html`（不需要联网、不需要服务器）。
2. 点“选择图片”一次选中全部图片（按文件名排序），或把图片拖进页面。
3. 在 ScreenToGif 录像机里框住红色画面，开始录制后按空格播放，播完停止录制。

页面上可以改录制尺寸、节奏、目标数字和标语。图片只在本机浏览器里处理，不会上传。
