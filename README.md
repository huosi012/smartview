# smartview

## count-animation.html

PPT 首页用的“千名学子圆梦”动画，发布会风格，顺易教育品牌蓝 + 橙配色：

- 整面墙按格子依次排开：内部是学生海报，四周一圈是成绩单，中间是蓝色玻璃面板。
- 学生海报从中心沿两条对称的螺旋臂飞出，带光尾，翻转着落到各自的格子；成绩单最后从画面外甩进四周，从顶部中间向两侧推进、在底部合拢。
- 镜头从中间推近的画面慢慢拉远，露出整面墙；中间数字从 1 跳到 1000，完成时“+”弹出、横向光闪过、整面墙扫过一道光，标语出现。

用法：

1. 用 Chrome / Edge 直接双击打开 `count-animation.html`（不需要联网、不需要服务器）。
2. 点“选择学生图片”选中全部学生海报，再点“选择成绩单图片”选中成绩单。都按文件名排序，格子比图片多时轮流重复使用。
3. 做 PPT 首页推荐点“全屏录制”（1080p 屏幕录出来就是 1920×1080）。在 ScreenToGif 里框住画面，开始录制后按空格播放，播完停止录制。
4. 放进 PPT 建议导出 MP4（插入 → 视频 → 此设备，开始方式设为“自动”）。GIF 只有 256 色，照片多时体积大、有颗粒。

页面上可以改录制尺寸、节奏、墙面密度、计数终点、顶部小字、标语和英文小字。字体都内嵌在文件里，不用联网。图片只在本机浏览器里处理，不会上传。
