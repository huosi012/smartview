在原图基础上并入的内花键内容:
- 渐开线花键孔参数表增加: 基圆直径 Ø199.685、齿形 短齿、基圆齿厚 8.034、齿面配合 c、加工方法 插齿、
  执行标准 Q/STB13.110.22 (齿形参照 JIS D2001);
- 原 "花键详图 3:1" 改为 B-B 局部剖视 5:1 (剖切位置在主视图 x=60 处), 含 Ø5 量棒示意;
- 技术要求增加第 4~6 条 (花键执行标准、M 值与综合通规检验、齿顶倒角/齿根圆角)。

链轮: z=23, p=88.9, d1=53.98, d=Ø652.88, da=Ø694.8, MR=705.33 (dR=Ø53.98), 齿形按 GB/T 1243-2006。
齿形尺寸 34.21/26.35 = 0.8·d1·(sinα, cosα) (α=55°-60°/z), 69.52/9.56 = 1.3·d1·(cos, sin)(180°/z)。

花键: m=2.5, z=85, α=20°, x=+0.8, d=Ø212.5, db=Ø199.685,
大径 D1=Ø218.25 H11, 小径 d1=Ø212.5 H7, 齿面定心, 齿面配合 c, 插齿。
计算校核: 基圆齿厚 8.034, 量棒 Ø5.0 测跨距 M=207.633 (图上 207.63)。
JIS D2001 (现收录为 JIS B1603:1995 附属书) 只规定 6~40 齿, z=85 超出其范围,
因此执行标准标为企业标准 Q/STB13.110.22, JIS D2001 仅作齿形参照。

```bash
pip install ezdxf matplotlib pillow numpy
python3 cad/make_sprocket.py            # 约 1 分钟 (含轴测图渲染; 加 --no-iso 复用已有图片)
```

B-B 局部剖视在模型空间按 15 倍绘制 (5:1 × 3), 尺寸数值均为真实值。
