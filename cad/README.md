# 链轮 2292-IH-000139 内花键图纸

| 文件 | 说明 |
| --- | --- |
| `2292-IH-000139_内花键.dxf` | CAD 图纸 (AutoCAD 2010 DXF, A3, 主视图 1:2, B-B 5:1) |
| `2292-IH-000139_内花键.pdf` / `.png` | 预览 (预览用开源字体, DXF 内为仿宋 simfang.ttf) |
| `spline_geom.py` | 20° 压力角渐开线内花键齿形与量棒 M 值计算 |
| `make_internal_spline.py` | 生成 DXF 与预览 |

花键参数: m=2.5, z=85, α=20°, x=+0.8, d=Ø212.5, db=Ø199.685,
大径 D1=Ø218.25 H11, 小径 d1=Ø212.5 H7, 齿面定心, 齿面配合 c, 插齿。
计算校核: 基圆齿厚 8.034, 量棒 Ø5.0 测跨距 M=207.633 (图上 207.63)。

执行标准: 企业标准 Q/STB13.110.22 (20° 压力角), 齿形参照 JIS D2001。
JIS D2001 (现收录为 JIS B1603:1995 附属书) 只规定 6~40 齿, z=85 超出其范围,
因此图上不直接标注 "按 JIS D2001"。JIS B1603 正文只有 30°/37.5°/45° 压力角, 也不适用。
