| 颜色 | 含义 | 在包装上 |

| **白** | 天山雪 / 洁净冷链 | 下半部乳白底，衬托金黄色产品 |

**三个记忆点**
1. **火山金线**：绿白分界线画成火山轮廓（中间带火山口凹槽），双层金线，直接点出“火山石”

3. **火山石板主图**：爆蛋堆在深灰多孔的火山石板上，顶上一颗切开露出爆汁肉馅，“火山石 + 爆汁”一眼看懂

## 6. AI 绘画部分与提示词

### 6.0 通用规则（每张图都要遵守）

1. **AI 只出图片，不出字**：品名、LOGO、卖点、净含量、标识全部用矢量字库排版。AI 生成的中文常有错字，印刷文件不能用
2. **“爆蛋”容易被 AI 画成鸡蛋**：提示词里写“油炸肉馅丸子”，并把“鸡蛋、蛋黄、蛋壳”放进负面提示词
3. **光源统一**：所有素材都用“左上方 45° 柔光 + 暖金高光”，合成时才不穿帮
4. **背景便于抠图**：食物和叶子用纯白底，热气用纯黑底（图层模式选“滤色”叠加）
5. **分辨率**：印刷要求 300dpi。主图区约 205×125mm，至少需要 **2420×1480 px**。生成后用超清放大（即梦超清、Midjourney Upscale、Topaz 等）放大 2 倍再用
6. **图片要和实物一致**：外皮颜色、个头、馅料要和真实产品对得上。可以用一张真实切面照片当参考图（垫图），在主图附近加一行小字“图片仅供参考，请以实物为准”
7. 适用平台：中文提示词适合即梦、可灵、通义万相、LiblibAI；英文提示词适合 Midjourney、Flux、Stable Diffusion（`--v 7` 可以换成你在用的最新版本）

## 7. 印刷与材质建议

- **材质**：冷冻食品常用 NY/PE 或 PET/PE 复合膜（耐 -18℃ 以下低温、抗穿刺）。1kg 装总厚度一般在 100–120μm，和彩印厂确认
- **印刷**：凹版印刷。金色用**专色金油墨**（如 PANTONE 871 C），或用镀铝膜 + 透明黄墨做出金属金
- **表面**：整体哑光油，品名和主图局部亮光，更有质感，也更显食欲
- **白墨**：透明膜要先铺白墨打底；开窗区不铺白墨
- **文件**：AI / PDF；CMYK + 专色单独通道；文字转曲；图片按实际尺寸 ≥300dpi；出血 3mm；热封区、撕口、喷码区按彩印厂刀版
- **偏色**：AI 图是高饱和 RGB，转 CMYK 后金黄色容易发灰。先在 PS 里软打样（CMYK）调整，再出数码样确认

## 8. 法规自查清单（以现行国标和当地市场监管要求为准）

- [ ] **品名 + 真实属性名称**：“火山石爆蛋”属于新创名称，必须在同一展示版面标示真实属性名称“速冻调制食品（肉糜类制品）”
- [ ] ⚠️ **“爆蛋”含“蛋”字**：如果产品不以蛋为主要原料，可能被认定为“易使人误解食品属性”。GB 7718 要求这种情况在品名邻近部位用**同一字号**标示真实属性名称。建议先找当地市监或法规顾问确认；如果需要同字号，把属性名称改成品名下方的第二行大字
- [ ] **净含量**：放在主展示版面，1kg 档字符高度 ≥4mm（本稿 7mm）
- [ ] **速冻调制食品（GB 19295）**：标示生制品 / 熟制品、贮存条件（≤ -18℃）、食用方法，按实际工艺填写
- [ ] **食用方法参数**：背面的温度和时间都是占位，必须研发实测后填写；生制品要写明“加热熟透后食用”
- [ ] **致敏物质**：新版 GB 7718-2025 改为强制标示（2027 年实施），建议现在就预留
- [ ] **营养成分表**：背面已按新版 GB 28050-2025 预留“饱和脂肪”“糖”两行
- [ ] **广告用语**：不用“最、第一、顶级、国家级”等极限词；“臻选好肉、一口爆汁”属于描述性用语
- [ ] **区域品牌 / 认证标识**：右上角标识位要取得授权才能用
- [ ] **喷码区**：生产日期 / 批号区域留白，不铺底色
- [ ] **条码**：EAN-13 黑条白底，不放在热封区和褶皱处，尺寸和静区按条码规范
